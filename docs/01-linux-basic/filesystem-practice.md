# Linux Filesystem Practice

## 1. 실습 목적

Linux 파일 시스템의 기본적인 디렉터리 구조와 경로 개념을 이해한다.

## 2. 실습 환경

- OS: Ubuntu on WSL2
- Shell: Bash
- Host OS: Windows
- Repository: linux-server-lab

## 3. 실습 내용

### 현재 경로 확인

```bash
pwd

현재 작업중인 디렉터리의 절대 경로를 확인한다.


ls
ls -l
 
현재 디렉터리에 존재하는 파일과 디렉터리를 확인한다.


ls / 

Linux 파일 시스템의 최상위 디렉터리 아래에 존재하는 주요 디렉터리를 확인한다.

### 홈 디렉터리 확인

Linux에서 사용자의 홈 디렉터리 위치를 확인한다.

pwd

현재 사용자의 홈 디렉터리 경로를 확인한다.

echo $HOME

환경 변수 HOME에 저장된 사용자의 홈 디렉터리 경로를 확인한다.

cd ~

홈 디렉터리로 이동한다.

pwd

이동 후 현재 경로를 다시 확인한다.


## 4. 실습 결과

### 4.1 현재 작업 디렉터리

실습 환경에서 `pwd` 명령어를 사용하여 현재 작업 디렉터리를 확인하였다.

실습 당시 작업 경로:

`/mnt/c/Users/홍승민/Desktop/SM-pf`

현재 작업 중인 디렉터리를 절대 경로로 확인할 수 있었다.

### 4.2 Linux 최상위 디렉터리

`ls /` 명령어를 사용하여 Linux 파일 시스템의 최상위 디렉터리를 확인하였다.

`/`는 Linux 파일 시스템의 최상위 디렉터리이며,
`/home`, `/etc`, `/usr`, `/var`, `/mnt` 등의 주요 디렉터리가 존재한다.

### 4.3 사용자 홈 디렉터리

`cd ~` 명령어를 사용하여 사용자의 홈 디렉터리로 이동하였다.

`pwd` 명령어를 통해 다음 경로를 확인하였다.

`/home/stave123`

또한 `echo $HOME`을 사용하여 HOME 환경 변수에 저장된 경로를 확인하였다.

### 4.4 Windows 파일 시스템과 Linux 파일 시스템

WSL2 환경에서는 Windows의 C 드라이브가 다음 경로를 통해 접근 가능하다.

`/mnt/c`

따라서 Windows의 바탕화면에 위치한 포트폴리오 폴더는 다음과 같이 접근할 수 있다.

`/mnt/c/Users/홍승민/Desktop/SM-pf`

이를 통해 WSL2의 Linux 환경에서 Windows 파일 시스템에 접근할 수 있음을 확인하였다.
