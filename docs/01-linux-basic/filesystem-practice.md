# Linux Filesystem Practice

## 1. 실습 목적

Linux 파일 시스템의 기본적인 디렉터리 구조와 경로 개념을 이해하고,
Linux 환경에서 파일과 디렉터리를 확인하고 이동, 생성, 복사, 이름 변경하는
기본 명령어를 직접 사용해본다.

또한 WSL2 환경에서 Windows 파일 시스템에 접근하는 방법을 익힌다.

## 2. 실습 환경

- Host OS: Windows
- Linux Environment: Ubuntu on WSL2
- Shell: Bash
- Repository: linux-server-lab
- Local Project Directory: `/mnt/c/Users/홍승민/Desktop/SM-pf`

## 3. Linux 환경과 현재 경로 확인

### 3.1 현재 사용자 확인

현재 Linux 환경에 로그인되어 있는 사용자를 확인하기 위해 `whoami` 명령어를 사용하였다.

```bash
whoami
```

실습 환경에서는 다음과 같이 확인하였다.

```text
stave123
```

### 3.2 현재 작업 디렉터리 확인

현재 작업 중인 디렉터리의 절대 경로를 확인하기 위해 `pwd` 명령어를 사용하였다.

```bash
pwd
```

실습 중 다음과 같은 경로를 확인하였다.

```text
/mnt/c/Users/홍승민/Desktop/SM-pf
```

`pwd`를 사용하면 현재 내가 어느 위치에서 작업하고 있는지 확인할 수 있다.

### 3.3 현재 디렉터리의 파일 확인

현재 디렉터리에 존재하는 파일과 디렉터리를 확인하기 위해 `ls` 명령어를 사용하였다.

```bash
ls
```

파일과 디렉터리의 자세한 정보를 확인하기 위해 `ls -l`도 사용하였다.

```bash
ls -l
```

`ls -l`을 사용하면 파일 권한, 소유자, 파일 크기, 수정 시간 등의 정보를 확인할 수 있다.

## 4. Linux 파일 시스템의 최상위 디렉터리

Linux에서 `/`는 파일 시스템의 최상위 디렉터리를 의미한다.

다음 명령어를 사용하여 최상위 디렉터리 아래에 존재하는 주요 디렉터리를 확인하였다.

```bash
ls /
```

주요 디렉터리는 다음과 같은 형태로 구성되어 있다.

```text
/
├── home
├── etc
├── usr
├── var
├── tmp
├── dev
├── proc
└── mnt
```

이번 실습에서는 특히 `/home`과 `/mnt`의 경로를 확인하였다.

## 5. Linux 경로(Path) 이해

Linux에서는 현재 위치에 따라 파일과 디렉터리의 경로가 달라진다.

예를 들어 다음 두 경로는 서로 다른 위치를 의미한다.

```text
/home/stave123
```

```text
/mnt/c/Users/홍승민/Desktop/SM-pf
```

`/home/stave123`은 Linux 환경에서 사용하는 사용자의 홈 디렉터리이며,
`/mnt/c/Users/홍승민/Desktop/SM-pf`는 WSL2를 통해 접근한 Windows의 C 드라이브에 위치한 프로젝트 디렉터리이다.

## 6. 사용자 홈 디렉터리

### 6.1 HOME 환경 변수 확인

현재 사용자의 홈 디렉터리 경로를 확인하기 위해 `echo $HOME` 명령어를 사용하였다.

```bash
echo $HOME
```

실습 환경에서는 다음과 같이 확인하였다.

```text
/home/stave123
```

`HOME` 환경 변수에는 현재 사용자의 홈 디렉터리 경로가 저장되어 있다.

### 6.2 홈 디렉터리로 이동

사용자의 홈 디렉터리로 이동하기 위해 다음 명령어를 사용하였다.

```bash
cd ~
```

Linux에서 `~`는 현재 사용자의 홈 디렉터리를 의미한다.

이동 후 `pwd` 명령어를 사용하여 현재 위치를 확인하였다.

```bash
pwd
```

결과:

```text
/home/stave123
```

## 7. WSL2에서 Windows 파일 시스템 접근

WSL2에서는 Windows의 파일 시스템에 접근할 수 있다.

Windows의 C 드라이브는 Linux 환경에서 다음 경로로 접근할 수 있다.

```text
/mnt/c
```

따라서 Windows 바탕화면에 있는 `SM-pf` 폴더는 다음 Linux 경로를 통해 접근할 수 있다.

```text
/mnt/c/Users/홍승민/Desktop/SM-pf
```

다음 명령어를 사용하여 해당 프로젝트 디렉터리로 이동할 수 있다.

```bash
cd /mnt/c/Users/홍승민/Desktop/SM-pf
```

이를 통해 WSL2의 Linux 환경에서 Windows 파일 시스템에 접근할 수 있음을 확인하였다.

## 8. 디렉터리 이동

### 8.1 특정 디렉터리로 이동

`cd` 명령어를 사용하면 원하는 디렉터리로 이동할 수 있다.

```bash
cd 디렉터리명
```

예를 들어 `practice` 디렉터리로 이동할 경우 다음과 같이 사용할 수 있다.

```bash
cd practice
```

### 8.2 상위 디렉터리로 이동

현재 디렉터리의 상위 디렉터리로 이동하기 위해 다음 명령어를 사용하였다.

```bash
cd ..
```

`..`은 현재 디렉터리의 바로 위에 있는 상위 디렉터리를 의미한다.

### 8.3 홈 디렉터리로 이동

다음 명령어를 사용하면 현재 사용자의 홈 디렉터리로 이동할 수 있다.

```bash
cd ~
```

## 9. 디렉터리 생성

새로운 디렉터리를 생성하기 위해 `mkdir` 명령어를 사용하였다.

```bash
mkdir test
```

위 명령어를 통해 `test`라는 디렉터리를 생성하였다.

`mkdir`은 "make directory"의 약자로 디렉터리를 생성할 때 사용하는 명령어이다.

## 10. 파일 생성

새로운 파일을 생성하기 위해 `touch` 명령어를 사용하였다.

```bash
touch hello.txt
```

위 명령어를 통해 `hello.txt`라는 파일을 생성하였다.

## 11. 파일 복사

파일을 복사하기 위해 `cp` 명령어를 사용하였다.

```bash
cp hello.txt backup/
```

위 명령어를 사용하여 `hello.txt` 파일을 `backup` 디렉터리로 복사하였다.

실습 결과 다음과 같은 구조가 되었다.

```text
practice/
├── backup/
│   └── hello.txt
└── hello.txt
```

`cp`는 파일이나 디렉터리를 다른 위치로 복사할 때 사용하는 명령어이다.

## 12. 파일 이름 변경

파일의 이름을 변경하기 위해 `mv` 명령어를 사용하였다.

실습 과정에서 `linux.txt`라는 파일을 만들려고 했으나 오타로 인해 다음과 같이 잘못 입력하였다.

```text
lunux.txt
```

이후 `mv` 명령어를 사용하여 올바른 이름으로 변경하였다.

```bash
mv lunux.txt linux.txt
```

이를 통해 `mv` 명령어는 파일이나 디렉터리를 이동하는 것뿐만 아니라
파일이나 디렉터리의 이름을 변경하는 데에도 사용할 수 있다는 것을 확인하였다.

## 13. 실습 디렉터리 구조

실습 과정에서 다음과 같은 디렉터리와 파일을 구성하였다.

```text
practice/
├── backup/
│   └── hello.txt
```

## 14. Vim 기본 사용

Linux 환경에서 텍스트 파일을 작성하고 수정하기 위해 Vim을 사용하였다.

파일을 열기 위해 다음과 같은 명령어를 사용한다.

```bash
vim 파일명
```

예:

```bash
vim vim-practice.txt
```

### 14.1 Vim 입력 모드

Vim을 실행하면 기본적으로 명령 모드로 시작한다.

파일에 내용을 입력하기 위해 `i` 키를 누르면 INSERT 모드로 전환된다.

```text
i
```

INSERT 모드에서는 일반적인 텍스트 입력이 가능하다.

### 14.2 Vim 명령 모드

텍스트 입력을 끝낸 후 `Esc` 키를 누르면 INSERT 모드에서 명령 모드로 돌아간다.

```text
Esc
```

### 14.3 Vim 저장 및 종료

명령 모드에서 다음 순서로 입력하면 파일을 저장하고 Vim을 종료할 수 있다.

```text
:
wq
Enter
```

일반적으로 다음과 같이 표현한다.

```text
:wq
```

`w`는 write의 약자로 저장을 의미하고,
`q`는 quit의 약자로 종료를 의미한다.

따라서 `:wq`는 파일을 저장한 후 Vim을 종료하는 명령이다.

## 15. 실습 중 발생한 문제와 해결

### 15.1 파일 이름 오타

#### 문제

파일을 생성하는 과정에서 `linux.txt`를 입력하려 했으나
실수로 `lunux.txt`라는 이름으로 파일을 생성하였다.

#### 해결

다음 명령어를 사용하여 파일 이름을 수정하였다.

```bash
mv lunux.txt linux.txt
```

#### 배운 점

Linux에서는 파일 이름과 경로를 정확하게 입력하는 것이 중요하다.

또한 `mv` 명령어는 파일이나 디렉터리를 이동할 뿐만 아니라
이름을 변경하는 용도로도 사용할 수 있다는 것을 확인하였다.

### 15.2 Vim의 입력 모드와 명령 모드 혼동

Vim을 처음 사용하면서 입력 모드와 명령 모드의 차이를 경험하였다.

기본적인 파일 작성 및 저장 과정은 다음과 같다.

```text
vim 파일명
↓
i
↓
내용 입력
↓
Esc
↓
:
↓
wq
↓
Enter
```

이를 통해 Vim에서 텍스트를 작성하고 저장한 뒤 종료하는 기본적인 과정을 익혔다.
