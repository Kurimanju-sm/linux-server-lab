# Linux Server Lab

Linux 및 IT 인프라 분야 취업을 목표로 진행하는 개인 실습 및 학습 기록입니다.

Linux 운영체제의 기본적인 사용법부터 서버 구축, 네트워크, 보안,
서비스 운영 및 장애 대응까지 단계적으로 학습하고 있습니다.

단순히 명령어를 암기하는 것이 아니라,
각 환경을 직접 구성하고 발생한 문제를 해결하는 과정을 기록하는 것을 목표로 합니다.

---

## 🎯 Goals

- Linux 운영체제 기본기 습득
- 서버 환경 구축 및 관리 경험
- 네트워크 기본 원리 이해
- SSH / Nginx 등 서버 서비스 구성
- Linux 권한 및 보안 관리
- 장애 상황 분석 및 troubleshooting 경험
- Git / GitHub를 활용한 작업 기록
- 실제 프로젝트에 인프라 지식 적용
